# Radio-T — плагин подкастов для Lampa

Плагин для **lampa.mx**, который подключается по ссылке GitHub и позволяет слушать подкасты **Радио-Т** во встроенном плеере Lampa.

## Возможности

- Автоматическая загрузка списка выпусков из RSS: `https://radio-t.com/podcast.rss`
- Автообновление списка выпусков (интервал настраивается)
- Ручное обновление кнопкой «Обновить»
- Воспроизведение в стандартном плеере Lampa с плейлистом (переключение между выпусками)
- Обложки выпусков
- Запасные CORS-прокси при недоступности RSS напрямую

## Установка

В Lampa: **Настройки → Плагины → Добавить плагин** → вставить ссылку:

```
https://cdn.jsdelivr.net/gh/shubladzetengiz/R@main/radio-t.js
```

или raw-ссылку GitHub:

```
https://raw.githubusercontent.com/shubladzetengiz/R/main/radio-t.js
```

## Настройка

После установки в **Настройки → Radio-T**:

- **RSS URL** — ссылка на ленту подкаста (по умолчанию `https://radio-t.com/podcast.rss`)
- **Автообновление списка** — включить/выключить периодическое обновление
- **Интервал автообновления** — 10, 30, 60 минут или 2 часа

## Использование

В боковом меню выберите **Radio-T**. Откроется список выпусков. Нажатие OK на выпуске запустит его в стандартном плеере Lampa; далее можно переключаться между выпусками внутри плейлиста.
